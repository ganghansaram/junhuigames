# 🐱 고양이 영웅 디펜스

초등학생도 바로 즐길 수 있는 **픽셀아트 타워디펜스** 게임입니다.
설치 없이 `index.html` 파일을 더블클릭하면 웹브라우저에서 바로 플레이됩니다!

## ▶ 플레이 방법
1. `index.html`을 더블클릭해서 엽니다. (크롬/엣지 등 아무 브라우저)
2. **[시작하기]** 를 누릅니다.
3. 오른쪽 상점에서 **영웅 고양이**를 고른 뒤, 잔디밭의 **빈 칸**을 클릭해 배치합니다.
4. **[웨이브 시작]** 을 누르면 적이 길을 따라 몰려와요.
5. 적을 잡으면 💰가 모이고, 그 돈으로 더 강한 고양이를 사서 배치하세요.
6. 적이 끝까지 가면 ❤️가 줄어듭니다. ❤️가 0이 되면 패배!
7. 8개의 웨이브를 모두 막으면 **승리** 🎉

## 🦸 영웅 고양이
| 고양이 | 비용 | 발사체 | 특징 |
|---|---|---|---|
| 🐱 냥냥이 | 50 | 🐟 물고기 | 짧은 사거리·빠른 연사 (기본) |
| ⚫ 검은 도둑냥 | 140 | 🗡️ 발톱 표창 | 사거리 최장·강한 한 방, 느린 연사 |
| ❄️ 눈송이냥 | 170 | ❄️ 눈송이 | 적을 얼려 느리게 만듦 |
| 🦁 사자 갈기냥 | 240 | 🔥 불덩이 | 범위 공격(여러 적 동시 타격) |
| 🐯 대장 호랑냥 | 400 | ⚡ 번개 구슬 | 강한 데미지+범위, 긴 사거리 |

> 고양이마다 **사거리·공격력·연사속도·발사체 모양**이 모두 다릅니다. 비쌀수록 강하거나 특별해요!

## 🌟 화면 구성
- 상단 **웨이브 진행바**와 **다음에 올 적 미리보기**로 상황을 한눈에!
- 오른쪽 끝 **우리집(🏠)**을 지키세요. 적이 도달하면 ❤️가 줄어요.
- 나무·덤불·꽃 같은 배경 소품과 폭발·파티클로 생생한 분위기.

## 💡 팁
- 배치한 고양이를 클릭하면 **판매**(60% 환불)할 수 있어요.
- 아래쪽 버튼으로 **속도 2배(⏩) / 일시정지(⏸) / 배경음악(🎵) / 효과음(🔊)** 을 조절합니다.
- 상점 고양이에 **마우스를 올리면** 자세한 설명이 풍선으로 떠요.
- 갈림길(길이 꺾이는 곳) 근처에 놓으면 더 오래 공격할 수 있어요.

## 🛠 만든 방식
- HTML + JavaScript (Canvas) 한 파일로 구성
- 외부 라이브러리 없이 순수 코드로 동작
- 코드에는 한글 설명(주석)이 들어 있어 읽으며 배우기 좋습니다.
